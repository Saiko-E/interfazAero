# AeroDesign

Sistema de adquisición de datos (DAS) desarrollado en Python para AeroDesign. Arquitectura asíncrona de lectura serial, renderizado dinámico con PyQtGraph y guardado continuo en disco duro.

## 🚀 Instalación Rápida (Linux)
Abre tu terminal, navega a la carpeta donde quieras descargar el proyecto y ejecuta:
```bash
git clone https://github.com/Saiko-E/interfazAero.git
cd interfazAero
chmod +x install.sh
./install.sh
